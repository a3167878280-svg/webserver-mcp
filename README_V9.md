# TinyMCP V9

V9 在 V8 的本地大模型与 HTTP 聊天基础上继续完善，加入上下文管理、可靠性诊断、更完整的聊天界面，以及可重复执行的核心测试套件。

## 相比 V8 的主要变化

- **上下文管理：** 按中英文特征估算 token，根据模型系列选择保守的上下文预算；过长的工具结果会自动截断，接近预算上限时会压缩较早的对话历史。
- **对话持久化：** 通过独立的异步持久化队列写入对话记录，避免 HTTP 请求线程被文件写入阻塞。
- **LLM 错误诊断：** 保存最近一次 HTTP/API 错误，并把供应商状态码和响应摘要传递给编排器和前端，不再只返回笼统的连接失败。
- **本地/自定义供应商模式：** 聊天页面可以在本地 Qwen3 服务和自定义 OpenAI 兼容 API 之间切换。本地实时模式在后端不支持“流式 + 工具调用”时自动禁用工具；工具模式保留工具执行，但使用非实时请求。
- **聊天体验：** 增加供应商设置、本地模式选择、对话标题、更稳健的对话创建与加载、可折叠工具卡片、思考标签过滤和更清晰的错误提示。
- **工具编排：** 支持用 `*` 一次禁用全部工具；每轮 Agent 调用前准备上下文，并在把工具结果发回模型前执行单结果大小限制。
- **自动化验证：** 启用 CTest，新增 MCP 解析器/序列化器、路由、插件能力测试，以及 `tests/` 下的基准测试目标。
- **学习文档：** 增加结构化的 `docs/` 教程系列和 JSON-RPC 请求链路说明，便于后续维护和学习。

## 构建与测试

```bash
cmake -S . -B build-tests -DBUILD_TESTING=ON
cmake --build build-tests -j
ctest --test-dir build-tests --output-on-failure
```
